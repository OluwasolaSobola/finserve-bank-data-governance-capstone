# FinServe Bank – Data Governance Operating Model

## Operating Model

A **federated Data Governance operating model** was designed to combine enterprise governance oversight with accountability within individual data domains.

This model enables governance standards and policies to be established centrally while Data Owners and Data Stewards remain accountable for governance within their respective business areas.

## Governance Structure

| Role | Responsibility |
|---|---|
| Data Governance Council | Governance oversight, policy approval, performance monitoring and resolution of escalated issues |
| Governance Lead | Coordinates the governance programme, framework, governance activities and implementation planning |
| Data Owners | Accountable for domain data, definitions, Data Quality, access and key decisions |
| Data Stewards | Day-to-day Data Quality monitoring, metadata, standards and issue management |
| IT / Data Team | Technical implementation of governance controls, systems and data integration |
| Compliance | Regulatory oversight and compliance monitoring |
| Data Analytics | Data usage, analytics and stakeholder communication |

## Data Governance Council

The Data Governance Council provides strategic governance oversight.

Key responsibilities include:

- Approving governance policies and standards
- Reviewing governance performance
- Resolving escalated data issues
- Supporting cross-domain decisions
- Monitoring governance implementation

Council representation includes business, compliance, data, technology and governance stakeholders.

## Data Ownership

Data Owners provide accountability for data within their domains.

Responsibilities include:

- Approving business definitions
- Establishing Data Quality expectations
- Approving appropriate access
- Reviewing significant Data Quality issues
- Supporting regulatory and governance requirements
- Making decisions on domain-level governance matters

## Data Stewardship

Data Stewards support the operational implementation of governance.

Responsibilities include:

- Monitoring Data Quality
- Supporting metadata management
- Applying governance standards
- Identifying and logging data issues
- Coordinating remediation
- Escalating unresolved issues to Data Owners

## Data Domains

The governance model covers key domains including:

- Customer
- Product
- Transaction
- Risk
- Finance

Domain-based stewardship forums support collaboration between Data Owners, Data Stewards and supporting functions.

## Governance Cadence

| Governance Activity | Frequency |
|---|---|
| Data Governance Council | Monthly |
| Stewardship Forums | Bi-weekly |
| Data Quality Reviews | Monthly |

## Issue Escalation

Data issues are managed at the lowest appropriate governance level.

Where resolution requires greater authority or cross-domain decision-making, issues are escalated through:

**Data Steward → Data Owner → Data Governance Council**
